# 👾 HoopRogue — 街球生存赛

> 原创篮球 Roguelike：**选人 → 打球 → 赢了三选一强化 → 变强 → 干翻 BOSS → 12 连胜夺冠**。
> 不用 NBA 真实数据、纯 Python 标准库、终端直接玩。

## 游戏循环

```text
选择球员原型（🎯神射手 / 💪突破手 / 🧠双能卫）
   ↓
赛前选节奏（稳扎稳打 / 均衡 / 极速跑轰）
   ↓
⚔ 比赛（4节 × 每节8回合，逐回合攻防模拟，中场可叫暂停布置）
   ↓
胜利 → 🎁 三选一强化卡 → 下一场对手更强
失败 → 💀 RUN OVER，结算本局
每 5 场一个 ☠ BOSS（区域联防 / 全场紧逼 / 双塔 / MVP队）
12 连胜 → 🏆 CHAMPION
```

## 开始

```bash
cd HoopRogue

python -m hooprogue                 # 交互游玩
python -m hooprogue --seed 42       # 固定种子（同种子 = 同一局）
python -m hooprogue --auto          # 自动模式：随机选人/抽卡打满一局（观战/测试）
python -m hooprogue --auto --quiet  # 浓缩观战：只看每场结果

python -m unittest discover -s tests   # 测试（10 个）
python tools/balance.py 60             # 平衡性抽查：批量自动跑局统计胜场分布
```

## 核心机制

* **逐回合攻防**：每个回合 = 失误判定 → 出手选择（三分/两分倾向）→ 命中判定 →
  篮板/快攻衍生球权。所有卡牌效果都在回合级别生效。
* **节奏选择**：稳扎稳打（少失误、少三分）/ 极速跑轰（多回合、多失误、多快攻）——
  按对手和你的卡组选。
* **中场暂停**：下半场二选一布置（加强进攻 +5% / 收缩防守 -5%）。
* **对手成长曲线**：`评分 = 30 + 9.0 × 轮次^0.85`，前缓后陡。
* **精英防守（对抗卡牌雪球）**：评分超过 70 后，对手会针对性掐断你的
  二次进攻/快攻（额外球权概率最多 -50%）并部分抵消卡牌加成（最多 -40%），
  保证后期不会因为数值钳制上限而形同虚设。
* **平衡性标定**：`tools/balance.py` 批量自动跑局。当前随机打法基准：
  平均 5.75 胜、夺冠率 25%（auto 是随机决策，人类选卡选节奏会更好）。

## 项目结构

```text
HoopRogue/
├── hooprogue/
│   ├── cards.py     # 卡牌池 + 效果计算（Mods）+ 抽卡
│   ├── player.py    # 球员原型 / 对手生成 / 评分曲线 / Boss 特性
│   ├── match.py     # 逐回合比赛引擎
│   ├── game.py      # Roguelike 主循环（选人/抽卡/失败结算/夺冠）
│   ├── ui.py        # 文本 UI 工具
│   └── __main__.py  # CLI（--auto / --seed / --quiet）
├── tests/           # 10 个测试：确定性 / 卡牌统计效果 / 护盾 / Boss / 完整 run
└── tools/balance.py # 平衡性抽查工具
```

## 与 HoopEvolution 的关系

HoopRogue 积累的三块东西未来直接喂给 **HoopEvolution**：

* **卡牌 = 离散战术基因**：进化算法的"战术个体"可以复用 Mods 数值结构；
* **Match 引擎 = reward 函数**：任意"卡组/战术"可以快速推演胜率分布；
* **balance.py = 评价流水线**：批量模拟 → 统计分布，就是进化算法的 fitness 评估器。
